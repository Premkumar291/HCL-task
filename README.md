# AI & Computer Vision Learning Repository

This repository organizes learning implementations, algorithms, and projects across **Artificial Intelligence** and **Computer Vision**.

---

## Repository Structure

### AI (`AI/`)
- **`machine-learning-basics/`**: Fundamental ML algorithms implemented from scratch / scikit-learn (Linear Regression, Logistic Regression, Decision Tree, K-Nearest Neighbors, Naive Bayes).
- **`neural-network-fundamentals/`**: Core neural network mechanics (perceptrons, activation functions, multi-layer networks, real estate price prediction).
- **`recurrent-neural-networks-nlp/`**: Sequential and natural language processing models (RNN, LSTM, GRU) applied to mobile review sentiment analysis.
- **`chatbot-llm/`**: Conversational assistant powered by Groq API and LLMs.

### Computer Vision (`Computer Vision/`)
- **`opencv-fundamentals/`**: Core image & video processing routines (rescaling, filtering/blurring, edge detection, morphological transformations, thresholding).
- **`feature-extraction/`**: Connected Component Analysis (CCA) and ORB (Oriented FAST and Rotated BRIEF) feature descriptors.
- **`cnn-image-classification/`**: Convolutional Neural Networks (CNN) for handwritten digit classification on the MNIST dataset.
